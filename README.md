# Users Management Server

A simple REST API built with Express.js for managing users.

## Features

- Get all users
- Add new users
- Express.js REST API
- CORS enabled
- JSON data handling

## Technologies

- Node.js
- Express.js
- CORS

## Run Locally

```bash
npm install
npm start

Server runs on:
http://localhost:3000
